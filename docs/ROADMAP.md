# Roadmap

## 0. Foundation

Licence, governance, architecture decisions, threat model, development setup,
CI, and documentation.

## 1. Local web core

Today, persistent assistant, plans, approval workflow, audit, diary,
policy/kill switch, backups, and responsive browser UI.

## 2. Workspace

Document metadata, folders, search, versions, import/export, and the
open-source document, spreadsheet, presentation, PDF, and calculator adapters.

## 3. Business connectivity

Read-only health and data contracts for ERP/CRM, calendar, meetings,
automation, reporting, and reliability; then narrowly scoped approved writes.

## 4. Hosted web SaaS readiness

Organisation tenancy, roles, isolation, hosted deployment, observability,
operational recovery, and third-party security review.

## Deferred

Native mobile applications. Responsive web remains the mobile-access route
until a dedicated mobile PRD is approved.
