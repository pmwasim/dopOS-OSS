# Licence decision required

The repository is public but does not yet have a final contributor licence.
Before accepting production code or releases, choose and add one:

- **Apache-2.0:** permissive, explicit patent grant, suitable for broad
  commercial adoption.
- **AGPL-3.0:** reciprocal network-copyleft, appropriate if hosted changes
  must remain open.
- **MPL-2.0:** file-level reciprocity, a middle ground for modular systems.

This is a legal/product decision. Record the selected licence, trademark
policy, contributor policy, and relationship to `dopOS-CSS` in this document
before the first public implementation release.
